# Security Policy

## Supported Versions

Until v1.0 GA, there is no stability guarantee and no tagged release yet — see
[`ROADMAP.md`](./ROADMAP.md) for the current state. Once released, the latest minor version and
the one before it are supported.

## Reporting a Vulnerability

Please use [GitHub Security Advisories](../../security/advisories/new) (Private vulnerability
reporting). **Do not report vulnerabilities in public Issues.**

- Initial response: within 3 business days
- Triage complete: within 10 business days
- Target fix timeline: Critical 14 days / High 30 days / Medium 90 days
- Coordinated disclosure: advisory published 7 days after the fix release

## Scope

**In scope:** the code in this repository, official container images, and official installers.

**Out of scope:** the logic of apps generated by users of this platform, and third-party products
this project bundles or depends on (e.g. Keycloak) — except that keeping bundled versions patched
is in scope.

## Safe Harbor

We will not pursue legal action against good-faith security research conducted under this policy.

## Design-level security documentation

This repository's security *architecture* (threat model, trust boundaries, the Security Gate
pipeline, the isolation model) is documented separately from this reporting policy — see
[`docs/design/02_SECURITY_セキュリティ設計書.md`](./docs/design/02_SECURITY_セキュリティ設計書.md).
